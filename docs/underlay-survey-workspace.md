# 图纸底图、设施与现场实测

## 数据边界

Layout JSON Schema 6 新增 `fixtures: []`，区域支持 `type: general` 和可选淡色 `color`。旧 v1～v5 布局经原校验入口迁移，原对象 ID、货位编码、房间门和区域绑定保持不变。服务端草稿 DTO 使用 Schema 6；C# 服务需要按此契约接收设施及通用区域，本次未实现后端。

IndexedDB database version 3 保留 drafts/history/snapshots/meta，新增 localResources（按 layoutId）与 projectBackups（按 id，并索引 layoutId/at）。表结构升级不删除数据；Layout JSON 迁移仍由独立事务执行，失败后保留旧数据并允许重试。

底图及实测记录只存本机资源，不进入 Layout、Runtime 或服务端草稿。普通导入/历史恢复保留资源并标记待核对。项目备份格式为 `wms-map-project` / `formatVersion: 1`，包含 layout 和 resources，图片使用 data URL。导入先解析、校验并解码图片，事务同时保存新草稿、资源及替换前完整项目；成功后才切换画面。恢复包可以在“图纸底图与项目备份”中恢复，不受普通布局 20 条历史限制。

## 现场操作清单

1. 切换编辑模式，展开左侧“图纸底图与项目备份”，上传 PNG/JPEG（不超过 20 MB / 5000 万像素）。未标定图片可先录入原点 X/Y、旋转及估算显示宽度。
2. 底图默认锁定；要拖动先取消锁定并保存设置，再点“摆放底图”。点“结束底图工具”继续编辑对象。
3. 获取图上两点实测距离后，点“两点标定”，在图片上依次点击两点，填米或毫米并应用。第一点位置固定，只改底图比例，既有对象完全不动。手动修改显示宽度会取消已有标定；修改原点或旋转保留比例。
4. 用房间表示有墙空间，用通用区域表示备货区/办公用途色块，用固定设施表示电柜/柱子/其他矩形设施。通用区域可包含货架和设施；设施与货架或通道/暂存区重叠会显示警告但不阻止保存。
5. 选择单个对象（门要选具体门），在右侧“现场实测”填写日期、实测值及备注；估算值不会填入实测输入。
6. 点“保存记录”只落盘记录；核对地图值和实测值后点“应用已保存实测值”。门越界或其他尺寸校验失败时保留记录和原布局。应用成功支持 Undo/Redo。
7. 应用后改变相关几何会显示“待复核”；恢复到完全一致的几何可以重新显示“已应用”。复制对象不继承实测记录；删除后记录保留，撤销可以恢复关联。
8. 离场前“导出项目备份”，携带底图和全部实测记录；普通“导出布局”只包含地图主数据。

## 人工复核

- 不同缩放/旋转下标定，检查第一点位置与量距；重新标定后对象位置不变。
- 锁定底图不拦截框选与拖动，三维及查看模式无底图；退出底图工具后 CAD 正常。
- 设施多选拖动、旋转、复制、删除和撤销；三维体块高度及区域颜色正确。
- 米/毫米换算、暂存记录、应用、缩小房间导致门越界、撤销和待复核提示。
- 刷新后底图/记录恢复；普通布局导入后待核对；项目备份导入及替换前项目恢复完整。
- 浏览器容量不足或图片损坏时应提示错误，当前模型及旧底图不丢失。

图片占用本机存储，完整项目恢复包也保存图片；建议定期导出备份。图纸不自动识别，也不推断 WMS 编码或勘察位置；现场定位仍使用既有 X/Y 属性。

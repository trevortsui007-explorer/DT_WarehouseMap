# 多房间布局与居中复位

Layout Schema 5 新增 `rooms: []`；原 `boundary` 保留为主空间。房间包含
`id/name/x/y/width/depth/rotation:0/doors`，门继续使用相对墙边的 side/offset/width。
房间、货架与业务区域共用世界坐标，移动房间不会隐式移动内部对象。
虚拟库位绑定仍只引用 areas，不引用 rooms。Runtime 不进入布局或历史。

旧布局和本地快照在事务内迁移；失败保留原数据并允许重试。数据库仍为版本 2，
仅布局 JSON 升级为 5。服务器草稿请求的 schemaVersion 同步为 5；实际 C# 服务需要支持该契约，
客户端不降级丢弃 rooms，也不实施数据库 DDL。

二维复位按实际整体范围适配并居中，预留顶部标签、底部统计的空间。
内部或外接房间允许重叠或分离；连接走廊不作越界提示，货架和暂存区检查房间并集的完整覆盖。
相邻房间墙与门相互独立，不自动合并墙或推断连通性。

## 人工复核

- 打开旧布局，检查原边界、原门及货位编码不变；点击复位和 Home，确认地图居中。
- 编辑模式新增两个房间，分别放到主空间内外，添加连接通道。
- 为两个房间分别新增门，拖动并检查 0.1 米吸附、Alt 精调、重叠与越界保护。
- 单拖房间，确认只有墙和门移动；Shift 同时选择货架后拖动，确认整体移动一次。
- 检查包含房间时旋转被阻止，纯货架旋转仍可用。
- 复制房间、删除房间、撤销重做，确认门身份独立、未选中的货架保留。
- 切换三维，检查房间墙线、门框及点击选择；导出再导入，并刷新检查自动保存。
